# P3隔离离线开发验收

更新：2026-08-08。P3只允许隔离离线开发；P1/P2真实窗口仍待验证。

## 强制边界

- 不注册或启用Windows任务；
- 不由看板、推送或现有定时入口调用；
- 不读写当前`v4/data`账户、持仓或成交文件；
- 不标记P3完成；
- P1/P2真实窗口失败时立即暂停P3并优先修复。

## 第一检查点（已通过）

| 项目 | 实现 | 状态 |
|---|---|---|
| 订单意图 | `PaperOrderIntentV1`绑定最终decision、快照、预算、股数和T+1日期 | 通过 |
| 成交实体 | `PaperFillV1`记录价格、费用、现金流和内容ID | 通过 |
| 往返实体 | `PaperRoundTripV1`严格配对买卖并计算净收益 | 通过 |
| 隔离账本 | `OfflinePaperLedger`要求调用方显式提供临时目录，无生产默认路径 | 通过 |
| 幂等 | 同一fill重复写入不重复成交，同一decision冲突成交被拒绝 | 通过 |
| 资金与仓位 | 现金守恒、资金不足、单只1/3上限和冻结预算均为硬门禁 | 通过 |
| T+1 | 卖出日期不得早于冻结的可卖交易日 | 通过 |
| 可重建与防篡改 | 从成交事件重建相同状态，重载时校验每笔内容ID | 通过 |
| 架构隔离 | 静态测试禁止依赖生产账户、调度器、看板及默认数据目录 | 通过 |

专项测试14项、全量自动测试171项通过。

## 第二检查点（已通过）

- `OfflineIntentFactory`只接受最终BUY决策与版本化buy/sell快照；
- 未验证交易日历或缺少下一开放交易日时fail-closed；
- 周五买入冻结为下周一可卖，SELL再次执行T+1门禁；
- `OfflineExecutionEngine`逐项执行，一项失败不污染其他成功成交；
- 原子replace失败保留原账本，重载状态不变化；
- 对账报告校验现金、持仓、fill唯一性、SELL与往返记录数量；
- 完整离线买入—次交易日卖出回放通过并可重建。

## 仍待开发

- 离线核心终审和更多边界故障场景；
- 未来从旧`SimAccount`迁移的只读设计与双写禁止规则；
- P1/P2真实窗口通过后才能评估生产接入，不在当前授权范围内。

以上全部完成也只能表示P3离线工程通过；在P1/P2真实窗口门禁解除前，P3仍不得连接生产链路或标记完成。
