# P3隔离离线开发验收

更新：2026-08-08。P3只允许隔离离线开发；P1/P2真实窗口仍待验证。

## 强制边界

- 不注册或启用Windows任务；
- 不由看板、推送或现有定时入口调用；
- 不读写当前`v4/data`账户、持仓或成交文件；
- 不标记P3完成；
- P1/P2真实窗口失败时立即暂停P3并优先修复。

| 项目 | 实现 | 状态 |

## 第二检查点（已通过）

- `OfflineIntentFactory`只接受最终BUY决策与版本化buy/sell快照；
- 未验证交易日历或缺少下一开放交易日时fail-closed；
- 周五买入冻结为下周一可卖，SELL再次执行T+1门禁；
- `OfflineExecutionEngine`逐项执行，一项失败不污染其他成功成交；
- 原子replace失败保留原账本，重载状态不变化；
- 对账报告校验现金、持仓、fill唯一性、SELL与往返记录数量；
- 完整离线买入—次交易日卖出回放通过并可重建。

## 仍待开发

- 继续补充非阻塞的长序列与多标的离线压力场景；
- P1/P2真实窗口通过后才能评估生产接入，不在当前授权范围内。

## 离线核心终审（已通过，但P3阶段未完成）

- 成交账本采用单文件原子提交和有序事件链，保存事件数与头部摘要；
- 删除、截断、重排或修改任一事件都会在重载时失败；
- 不可变订单日志补齐决策→订单→成交血缘，对账可验证所有fill均有order；
- SELL必须匹配原持仓decision、代码和股数，且成交时间晚于BUY；
- 同一股票平仓后可由新decision重新开仓并正确对账；
- 最多3只持仓和单只1/3资金上限均为账户硬门禁；
- ADR-0008规定未来只能原子单次切换，禁止旧账户与P3双写；
- 静态架构测试禁止现有生产入口导入任何P3模块。

以上全部完成也只能表示P3离线工程通过；在P1/P2真实窗口门禁解除前，P3仍不得连接生产链路或标记完成。
