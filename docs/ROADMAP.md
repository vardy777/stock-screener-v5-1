# 项目路线图

> 当前执行状态：P3/P4/P5 已于 2026-08-09 经授权切换生产。下文各阶段中的“仅离线/禁止切换”是开发时门禁的历史说明，不再描述当前部署；阶段仍为 `in_progress`，直到真实窗口验收完成。`research_locked` 始终有效。

> 2026-08-09 更新：用户已单独授权并完成 P3/P4/P5 本地生产切换。此前“仅离线、禁止切换”的限制已被这次明确授权替代，但 P1/P2 真实窗口门禁和 `research_locked` 没有解除。P3/P4/P5 仍为 `in_progress`，直到真实任务、推送、成交与恢复链路通过现场验收。

阶段原则上顺序推进。经用户明确授权，P3可以在P1/P2真实窗口待验期间进行离线开发，但不得启用调度、接入每日模拟成交生产链路或标记完成；任何P1/P2真实窗口失败均立即暂停P3并优先修复。

## P0 项目基线、编码与事实校正（已完成）

目标：建立唯一项目入口、机器可读状态、模块边界和自动检查。

退出条件：

- ChatGPT/Codex进入仓库能从 `AGENTS.md` 和 `PROJECT.md` 恢复上下文；
- 项目状态、架构、模块、运行手册、决策记录齐全；
- V4无V3导入检查、文档存在性检查和全量测试通过；
- 当前运行事实与已知问题记录准确。
- 关键文档可按 UTF-8 严格解码，状态工具在 Windows 控制台和重定向日志中显式输出 UTF-8；终端显示问题不得误判为文件损坏。

## P1 唯一行情网关、时间与市场状态契约（离线完成，真实窗口待验）

目标：建立唯一行情网关；核心模块只接受版本化 `MarketSnapshotV1`；禁止 naive datetime 自动补时区；市场状态成为版本化契约；删除所有松散 DataFrame/字典行情绕行路径。

退出条件：所有行情进入核心前均由唯一网关冻结为快照；未来时间、批次延迟、naive datetime、停牌、涨跌停和缺失行情均有测试；严格数据与 paper-only 降级路径在字段和目录上完全隔离；市场状态携带输入快照血缘；不存在核心模块直接调用行情提供方或接受松散行情对象的路径；离线验收和真实 09:25、14:49、14:50、次日 09:30 窗口验收通过。

## P2 候选与决策唯一事实源（离线完成，当前等待真实窗口）

目标：使 `candidate_journal` 成为候选与决策的唯一事实源；看板、推送和执行只投影最终实体。

P0问题：修复日志先保存旧门禁、母池重排分数口径变化、固定80分阈值不稳定。

退出条件：删除 `dashboard_state.json` 的候选业务职责；`runtime_state.json` 只含派生诊断；确认集合严格为母池子集；空仓与阻断可区分；最终实体强制携带输入快照、排序、策略和市场状态血缘；从冻结 `MarketSnapshotV1` 开始的全链路回放确定性一致；离线验收和真实窗口验收通过。

## P3 模拟账户与执行引擎（仅离线开发中）

目标：自动买卖、费用、滑点、仓位、T+1、幂等和失败重试形成独立模块。

当前附加门禁：P1/P2真实窗口全部通过前，P3产物只能用于隔离的临时目录和自动测试；禁止注册或启用Windows任务，禁止写入当前`v4/data`模拟账户、成交和持仓生产文件，禁止由看板或现有定时入口调用。

退出条件：端到端回放覆盖买入、空仓、部分失败、次日卖出、节假日顺延；账户
永不重复成交；资金与逐笔记录可对账。

## P4 调度、推送与运行可靠性

当前授权：仅允许隔离离线契约开发；禁止注册或启用Windows任务、发送真实PushPlus、接入P3生产成交链路或标记阶段完成。

目标：把业务调度从看板进程解耦，提供心跳、SLA、补偿和告警。

退出条件：看板停止不影响交易日任务；任务漏跑可补偿且不重复；09:25和14:50
推送有明确成功回执；故障能在看板和PushPlus告警。

## P5 看板与可观测性

当前授权：只允许并行开发只读读模型和隔离预览；现有8898不得改接，禁止任何行情、选股、推送、交易或账户写操作。

目标：8898成为项目控制台，而不只是数据页面。

退出条件：展示状态机、数据时效、当日链路、账户、交易、胜率、回撤、原因码、
任务SLA和证据分层；所有数字有口径说明和来源时间。

离线状态：读模型、真实文件零写入适配器、来源哈希、资金流、闭合往返、权益/回撤、
多故障场景、只读HTTP和桌面/移动视觉验收已通过。8898仍未改接，阶段不得标记生产完成。

## P6 研究数据集与评估

目标：持续积累无偏严格样本，完成Walk-Forward和压力测试。

退出条件：严格配对样本达到最低门槛；数据血缘可复现；窗口稳定性、费用敏感性、
行业和市场状态分层报告通过预先定义的验收标准。

## P7 模型训练、注册与发布

目标：训练可校准、可回滚、可审计的生产候选模型。

退出条件：训练只读严格数据；模型、特征、策略和报告哈希一致；发布清单原子化；
生产门禁全部通过后才允许将状态从 `research_locked` 改为准入。

## P8 运维与历史资产归档

目标：归档V2和根目录旧实现，完善备份、恢复、升级与长期维护。V3已于2026-08-09完成可恢复退役。

退出条件：运行路径只含V4；数据备份与灾难恢复演练通过；历史代码只读归档；
发布和回滚流程文档化。

离线状态：内容寻址备份、幂等创建、成员哈希、防路径穿越、损坏检测和空目录隔离恢复
V3代码和数据已完成内容寻址备份、隔离恢复校验并移出工作树；真实生产恢复、V2和根目录历史归档仍未执行。
