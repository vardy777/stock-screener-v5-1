# P6—P8离线契约验收

更新：2026-08-08。本报告只证明不依赖真实交易窗口的软件契约，不证明策略有效，
不允许发布模型或解除`research_locked`。

## P6研究评估

- 严格数据必须完整携带14:49特征、14:50买入、次日09:30卖出、日历、盘口、
  一档流动性、逐日股票池与历史名称验证字段；
- 日期/代码重复、代理样本、缺失控制列、NaN/Inf、覆盖率低于95%均失败关闭；
- Walk-Forward维持既定500笔样本外交易、胜率95%下限、PF、窗口一致性、回撤门槛；
- 普通与双倍滑点压力报告必须绑定同一数据集，全部窗口使用冻结策略。

当前严格样本不足，因此只完成契约，不生成合格报告。

## P7模型发布

- 发布清单继续由`PublishedModelRegistry`校验模型、特征、策略、训练数据哈希；
- 新增终审将训练说明绑定到普通与压力报告文件哈希；
- 诊断模型、research-only模型、修改后的报告或产物均不能通过；
- 审计函数明确不修改生产状态。

当前没有符合门禁的生产模型，因此未发布任何模型。

## P8灾备

- 备份清单包含每个文件的相对路径、大小和SHA-256，备份ID由清单内容寻址；
- 相同输入与时间幂等，拒绝在源目录内部创建备份；
- 恢复前验证成员集合、大小、哈希和安全路径；
- 只允许恢复到空目录，并在恢复后逐文件复核。

只在临时目录演练；未备份或覆盖生产数据，未归档V2/V3。
