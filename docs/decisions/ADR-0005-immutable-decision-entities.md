# ADR-0005：候选链路只发布不可变最终决策

- 状态：已接受
- 日期：2026-08-08
- 阶段：P2

## 背景

旧流程在母池关联前评估尾盘候选并写入日志，随后补充关联并重新评估，但没有把
最终门禁结果写回日志。推送、看板和执行因此可能读取不同阶段的阻断理由。

## 决策

1. 09:25只发布一次版本化 `MorningPoolV1`；
2. 14:50按“母池关联→最终门禁→发布 `ConfirmationDecisionV1`”执行；
3. 同一交易日实体内容不可覆盖；完全相同的重试按ID幂等返回；
4. 候选和市场状态深层冻结，不能通过嵌套字典原地修改；
5. 确认结果使用 `BUY`、`EMPTY`、`BLOCKED` 和稳定机器原因码；
6. 推送、看板和模拟执行后续只读取最终确认实体，不现场重新解释原因。

## 结果

候选日志成为同一交易日决策链的唯一事实来源。评分口径重构将在后续P2检查点
完成，不在本决策中改变策略阈值或利用未来收益调参。
