# ADR-0007：研究模拟使用无分数截断的Top1完整性政策

- 状态：已接受
- 日期：2026-08-08
- 阶段：P2

## 背景

规则分是横截面排序尺度，不是胜率或校准概率。固定80分既缺少统计依据，又会让
研究模拟只记录人为挑选的样本，降低后续策略验证的无偏性。

## 决策

研究模拟政策固定为 `paper-top1-integrity-v1`：

- 只接受同日09:25母池关联后的14:50最终Top1；
- 要求 `base_score + confirm_delta = decision_score` 且版本血缘正确；
- 全市场新鲜行情覆盖不低于95%；
- risk-off、行情或价格无效、模拟/非V4来源均空仓；
- 不设任意规则分最低值；
- 账户层只处理仓位、现金、整手和费用，不再二次执行规则分门槛；
- 生产模型的概率和风险门禁与paper政策保持独立。

## 结果

paper交易用于无偏积累Top1策略样本，不代表生产准入或盈利保证。生产状态继续为
`research_locked`，后续模型仍必须通过严格样本、Walk-Forward和压力测试门禁。
