# ADR-0004：版本化点时行情与证据质量隔离

- 状态：已接受
- 日期：2026-08-08
- 阶段：P1

## 背景

旧流程以 DataFrame 松散字段传递行情，只有 `quote_time` 和抓取时的新鲜度判断。
它无法区分交易所时间、供应商时间、机器接收时间和批次耗时；naive datetime
还会被自动解释为上海时区。这些行为不足以支撑严格点时证据。

## 决策

1. 以 `QuoteV1`、`MarketSnapshotV1`、`SnapshotQualityV1` 作为V4行情边界；
2. 所有时间必须显式带时区，禁止自动补时区；
3. 交易所、供应商、接收、批次开始和结束时间分别保存；
4. 新浪只提供一个行情时间时，`provider_time` 保留相同值并以
   `provider_time_source=same_as_exchange_time` 明示来源，不伪造独立时钟；
5. strict与paper-only共用质量原因码，但paper-only只可容忍全市场覆盖不足和
   批次延迟；未来时间、跨日、停牌、涨跌停锁死和盘口缺失仍然失败关闭；
6. 旧DataFrame入口逐步迁移，不用一次性切换破坏两次必要推送。

## 结果

严格证据可审计地拒绝非因果和不完整样本；paper-only降级不会混入生产训练证据。
后续快照写入必须按证据 cohort 使用不同目录和清单。
