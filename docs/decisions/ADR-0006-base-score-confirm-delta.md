# ADR-0006：早盘基础分与尾盘确认增量分离

- 状态：已接受
- 日期：2026-08-08
- 阶段：P2

## 背景

旧流程在早盘全市场上计算百分位分数，尾盘却只对3—5只母池成员重新计算相同
百分位。相同股票的分数因此取决于参与重排的小池组成，不再与早盘分数可比。

## 决策

1. 早盘全市场百分位冻结为 `base_score`；
2. 尾盘不再计算母池内百分位，只使用当时可见的收益变化、收盘位置变化和量比
   变化计算固定公式 `confirm_delta`；
3. `confirm_delta` 限制在 -5至+5分；
4. `decision_score = base_score + confirm_delta`，限制在0至100分；
5. 尾盘缺少早盘基础分的股票直接排除；
6. 公式版本为 `v4-base-plus-confirm-delta-v1`，不得依据未来盈亏临时调参。

## 结果

早盘与尾盘分数可解释、可比较，小母池组成不再改变基础排名尺度。固定80分执行
门槛仍属独立技术债，将由预先声明的覆盖/风险政策替换。
