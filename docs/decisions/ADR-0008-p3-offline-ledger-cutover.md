# ADR-0008：P3隔离事件账本与未来单次切换

- 状态：已接受（离线范围）
- 日期：2026-08-08
- 阶段：P3

## 背景

旧`SimAccount`直接覆盖单一JSON并依赖当前日期，缺少稳定订单、成交和事件链身份。直接在现有生产路径中渐进双写，会形成两个账户事实源，且故障时无法判断哪个结果有效。

## 决策

1. P3离线开发使用`PaperOrderIntentV1`、`PaperFillV1`、`PaperRoundTripV1`和带事件链的`OfflinePaperLedger`；
2. P1/P2真实窗口通过前，现有看板、调度、`SimulationEngine`、`SimAccount`和`paper_trade.py`禁止导入P3模块；
3. 禁止旧账户与P3账本双写，任何时刻只能有一个模拟账户事实源；
4. 旧账户未来只能通过只读、可校验的迁移报告导入，旧记录不得自动晋升为新P3证据；
5. 未来切换必须先备份、离线对账、冻结旧写入，再原子修改入口；失败时恢复旧入口，不能合并两边新增成交；
6. 当前P3产物只允许写入调用方显式提供的隔离目录。

## 后果

- 当前可以完整验证新账户模型而不影响每日系统；
- 暂时保留旧模拟账户生产行为，但它不代表P3验收通过；
- 生产迁移需要P1/P2真实窗口通过以及新的明确授权；
- 静态架构测试负责阻止提前接入。
