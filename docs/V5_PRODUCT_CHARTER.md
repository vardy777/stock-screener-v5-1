# V5 产品章程

V5 是在 V4 可靠底层之上建立的、以研究产品闭环为中心的独立层。它的目标是持续记录无偏、可回放的模拟交易证据，而不是制造推荐、承诺收益或发出券商订单。

## 用户可见闭环

```text
可信全市场快照 → 漏斗与母池 → 尾盘确认 → 本地模拟成交
→ 次日退出 → 绩效/基线比较 → 今日决策与研究看板
```

## V4复用与边界

- 只读复用：`MarketSnapshotV1`、时区/时钟契约、不可变哈希、P3账本格式、P4任务工件和严格研究门禁。
- V5独立：采集会话、多源质量报告、候选漏斗、产品读模型、绩效和基线报告。
- 明确淘汰：看板直接拼接运行时JSON、单一来源无会话质量报告、用个股停牌/涨停关闭整个市场、把排序分显示为胜率。
- 在单独授权与真实窗口验收前，V5不得更换P4调度、8898入口、P3写者、PushPlus或任何生产数据。

## 不可违反约束

- `research_locked`、无券商订单、95%覆盖门槛、因果时钟和严格样本不可补写继续有效。
- 交易确认只能来自同日09:25母池子集。
- 严格、模拟账本、代理回测三类证据永久分开。
- 没有冻结盘口时不得显示买卖价格。

## 分阶段验收

| 阶段 | 离线验收 | 真实窗口验收 |
|---|---|---|
| V5-A 数据生产 | 多源选择、失败关闭、会话与质量持久化、回放 | 09:25/14:49连续10日≥95%覆盖 |
| V5-B 候选漏斗 | 全层淘汰原因、母池子集、分位和血缘 | 每日早盘/尾盘实体匹配 |
| V5-C 模拟闭环 | 拒单、恢复、对账、基线/绩效契约 | 买入至次日卖出完整往返 |
| V5-D 产品看板 | 四页只读产品投影、空数据表达 | 与实际实体逐字段一致 |
| V5-E 研究与模型 | 严格数据/WF/发布契约失败关闭 | 达到门槛后再评审 |

## 迁移与回滚

V5先以影子事实源运行。切换前必须：冻结V5版本、全量离线验收、连续真实影子验收、备份V4任务与数据、只允许单写者。回滚只需停止V5影子/产品入口；V4实体与账本不得由V5修改。
