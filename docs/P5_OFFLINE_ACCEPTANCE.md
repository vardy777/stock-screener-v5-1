# P5隔离只读看板验收

更新：2026-08-08。P5只允许隔离离线开发；现有8898生产看板未改接。

## 架构决策

- 保留未来用户地址`http://localhost:8898/?mode=chase`；
- 放弃继续扩展现有单文件看板，采用新的只读读模型与模块化页面；
- 当前预览只运行于临时8899，验收后关闭；
- 新旧看板禁止双重解释业务事实，未来只能一次性原子切换；
- 禁止P5抓行情、选股、重算决策、推送、买卖或重置账户。

## 第一检查点（已通过）

| 能力 | 验收事实 |
|---|---|
| 唯一读模型 | `DashboardReadModelV1`为内容寻址、带时区、确定性只读投影 |
| 当日链路 | 展示09:25母池、14:49冻结、14:50决策、模拟买入和次日卖出实体状态/ID |
| 候选关联 | 同屏展示早盘排名、基础分、确认增量、最终分、策略、原因码、母池与决策ID |
| 市场状态 | 展示涨跌家数、涨跌停、成交额、覆盖率、来源、截至时间、快照和市场状态ID |
| 市场情绪 | 只使用冻结宽度统计并明确“不是盈利概率” |
| 资金流 | 统一状态、来源、时间、单位和板块净流入；陈旧数据明确告警 |
| 模拟账户 | 仅闭合往返进入胜率；计算净盈亏、均值、中位数、最大回撤和费用口径 |

| 降级 | 母池、决策、市场、资金流、心跳缺失均形成稳定问题码，不用0伪装正常 |

| 兼容性 | `/?mode=chase`可访问；现有`v4/dashboard.py`未导入P5 |

P5专项5项、全量自动测试211项通过。

## 浏览器验收

- 桌面端1265px：8个控制模块，根页面无横向溢出；
- 移动端375px：修复表格撑宽后`scrollWidth=clientWidth=375`；
- 页面无表单、按钮或任何写操作控件；
- 正常冻结场景的链路、候选、市场、情绪、证据、任务和统计口径均可见。
